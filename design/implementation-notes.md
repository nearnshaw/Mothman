## 2026-11-04 · Mothman behaviour: HTN planner (owner call)

- The Mothman's behaviour (the states in GDD §7: unseen, watching, pressing, speaking, judging) will be authored as an HTN domain with the `htn-domain-authoring` skill, from decentraland/sdk-skills PR #155 (branch `feat/htn-planner`, head commit `a28dbc928571a7e27ea3bd2c39eef4b3e2464c33`, still a draft, unreleased).
- The skill targets the Decentraland HTN module, a TypeScript port of `urosidoki/htn_planner` living in the `sdk7-test-scenes` repo (scene `96,-11-htn-planner`). Ordered task decomposition against game-owned facts; the scene executes actions and replans; no simulated effects, no automatic plan repair. The facts the Mothman plans against will be things like *beam on for N seconds*, *beam pointing at me*, *player inside a dome*, *moths dropped in the beam*, *reveal delivered*.
- The module itself is not installed in the scene yet. The skill says to describe the files and scripts before adding them and to ask for confirmation; do that at build time.

### How the skill is installed in this scene

- The Creator Hub links every scene's `.claude/skills` and `.agents/skills` to one shared, hash-tracked folder (`creator-hub/sdk-skills/skills`, see its `meta.json`), which the Hub re-syncs from the published release. An unreleased skill placed there would affect every scene and could be removed on the next sync.
- So this scene's `.claude/skills` is now a **real directory**: 35 unchanged skills are symlinks back to the Hub's shared copies (they keep receiving updates); `htn-domain-authoring` is a local copy; `npcs` and `sdk-scenes` are **local patched copies** carrying the PR's routing changes (`npcs/references/behavior-selection.md`, the HTN row in `sdk-scenes`). Those two will *not* receive Hub updates until the PR ships and the local copies are replaced by symlinks again. `.agents/skills` symlinks to `.claude/skills`.
- When PR #155 merges and reaches a Hub release: delete the three local folders and restore the symlinks (`ln -s "<shared>/npcs" .claude/skills/npcs`, same for `sdk-scenes`; `htn-domain-authoring` will then exist in the shared folder).
- If the Hub ever recreates the whole-folder symlink on scene open, the local install would need redoing from the PR diff; not observed, just untested.

## 2026-11-04 · First playable: how it is built

- **HTN install:** `src/htn-planner/` (runtime) and `tools/htn-authoring/` (Node compiler) copied whole from sdk7-test-scenes at commit `122a3ff2e87b7e89a6c6ea415eb140dd51716125`; `src/htn-planner/SOURCE.json` records the pin. `htn.config.json` maps `src/npc/mothman/mothman.domain` → `mothman.htn.ts` (`mothmanDomain`). npm hooks: `prestart`/`prebuild`/`predeploy` run `htn:generate` (+ `htn:notices`). `.dclignore` excludes the authoring sources; `htn-notices.txt` ships.
- **Host pattern:** `PlanRunner` used directly (HOW-TO §5), not `GuardSquad`: the Mothman has no patrol route or perception model, and the game owns everything. Facts are rewritten every tick; a string key of the decision-relevant facts triggers a replan when it changes or when the plan ends; the running executor is cancelled on replan. `!speak` is uninterruptible (the host suspends replanning while speaking).
- **Forest generator:** `scripts/gen-forest.py` writes primitives into `main.composite` in edit mode (registers `inspector::Nodes`, `core-schema::Name`; no `inspector::TransformConfig` because the file did not have one). It removes its own previous entities by the `Forest:` name prefix, so it is re-runnable after a parcel change. Run only with the scene closed in the Hub.
- **Flashlight:** spot `LightSource` with `shadow: true` parented to `engine.CameraEntity` (aim-item pattern). `beamHits(point)` is the cone test used for eyeshine and the dead-dog beat.
- **Sounds:** generated by a numpy script (scratchpad), OGG via ffmpeg. Replace when real audio exists.
- **UI:** coded React-ECS (`src/hud.tsx`), not editable in the UI Designer; per-frame alpha driving is simpler in code for a prototype.

## 2026-11-04 · Lessons from the in-world pass

- **A camera-parented spotlight with `shadow: true` is shadowed by the avatar's own head.** The lamp must sit ~0.5 m in front of the camera, or cast no shadows. Found by screenshot; the symptom is a beam that only lights things above eye level.
- **HTN replan key = external events only.** Facts the NPC changes by acting (distance, the player's fear) go into the world for branch selection but not into the key that triggers a replan, or his own progress cancels his plan. Same for any clock the host resets as a consequence of an action: reset it when the plan ends, not mid-plan.
- **Explorer MCP press_input with an aim point needs a collider at that point.** The book GLB with `visibleMeshesCollisionMask: 1` works with `entityId`; a guessed world point misses a 0.4 m prop.
- **Catalog assets** were fetched with `scripts/dl-asset.mjs` (asset-pack items: stylized_pine_tree, green_birch_tree, autumn_birch_tree, dark_book, blank_post_sign) and one OpenDCL model (`assets/Models/fog.glb`). The script lives under `scripts/`, which `.dclignore` excludes from deploys.

## 2026-11-04 · Lessons from pass 4

- **The Hub editor autosaves over a generated composite.** Confirmed: after the owner's session the file on disk held the old primitive forest and none of the documents. `scripts/gen-forest.py` must run with the scene closed in the editor (the preview alone is fine), and it now removes both `Forest:` and `Document:` entities before writing.
- **Explorer MCP entity ids are not composite ids.** `press_input` needs the runtime id; `list_scene_entities` with `crdtEntity: <composite id>` maps one to the other (1426 → 918 here).
- **Pointer-clickable primitives in the composite:** `core::MeshCollider` with `collisionMask: 1` (CL_POINTER) on the entity that gets `pointerEventsSystem.onPointerDown`; children may carry the visible meshes. Textured planes use `core::Material` pbr `texture.tex.$case = "texture"` with `src`, `wrapMode`, `filterMode`.
- **Scene state must not flow straight from a locked executor into a kill.** When the voice ends, wipe the scare flag and the lit clock; otherwise facts gathered before the reveal (scared, lit long) satisfy `take` on the first replan.
- **UI that must wait for the player** (a document) is a state flag plus an input check with a short guard against the press that opened it; never a timer.

## 2026-11-04 · Lessons from pass 5 (the 12 × 12 build)

- **Blender headless is the model pipeline.** `/Applications/Blender.app/Contents/MacOS/Blender -b --python script.py -- out.glb`; build Z-up with the front at −Y, export with `export_yup=True`. Clips go out as NLA tracks (`export_animation_mode='NLA_TRACKS'`, one track per action; Blender 5 needs `strip.action_slot = action.slots[0]`), and the Animator in the scene plays them by name. Scripts live in the session scratchpad; the GLBs in `assets/Models/`.
- **Mirrored bones, same-sign keys.** Two hand-placed wing bones with roll 0 have local X axes pointing opposite ways in world space, so keying them with opposite signs (the intuitive "mirror") makes one wing rise while the other falls. Check by sampling both bone tails per frame after import; they must have equal Y.
- **The engine mirrors X on GLB import.** A door leaf built to run +X from its pivot runs −X in the scene; either hinge it on the other jamb or yaw it 180°. Found by screenshot (the door stood beside the doorway).
- **A composite error breaks the build silently in the preview.** A bad `GltfContainer.src` (a tuple instead of a path) made `sdk-commands build` throw inside the composite encoder, and the watcher kept serving the previous bundle, so the reload showed the old scene. Run `npm run build` after regenerating and read its output before trusting a reload.
- **Changing the parcel count while the preview runs drops the scene.** After 8 × 8 → 12 × 12 the Explorer reported no scene at the parcel until the preview was re-entered; `teleport` to the base parcel brings it back once the server has the new `scene.json`.
- **Rotation sign for a pitched roof:** in the engine a positive Z rotation lifts a box's +X end. The left panel (ridge end at +X) takes +24°, the right −24°. A flat box gable sticks out above the eaves; six stepped strips that narrow toward the ridge read as a plank gable.
- **The generator shadows nothing by accident:** a roof variable named `RL` overwrote the road length used by the final print. Keep generator-local names prefixed.
- **InputModifier** on `engine.PlayerEntity` with `disableJump`, `disableDoubleJump`, `disableGliding` is enough to keep the player on the ground; it lifts itself when the player leaves the scene.
- **A primitive sphere cannot be an earth mound with a doorway.** An ellipsoid wide enough to cover the room reaches 2 m past the headwall and swallows the step and the door; found by screenshot (the beam blew out on bare earth at 1 m). The mound is now a half-ellipsoid open shell GLB (`assets/Models/mound.glb`, unit radius, Blender bisect without fill) scaled per bunker, flush with the back of a 12 m headwall with a parapet; the headwall hides the open edge, and the shell carries a collider so the player cannot walk into the earth.

## 2026-11-05 · Lessons from pass 6 (owner notes 4)

- **`TextShape` is unlit.** White letters read bright white in a black scene. For a sign that must go dark with the scene, put a lit `MeshRenderer.setPlane` with a pale PBR material behind black letters; the flashlight lights the board, the letters are only visible on it.
- **A plane reads unmirrored from its −z side** (advanced-rendering skill, confirmed by the owner's report): the map on the cabin's back wall had a 180° yaw and read mirrored to a player standing inside (at −z of it). The bunker stencils, unrotated and read from −z, were right all along.
- **Box faces turn a texture:** on ±x faces the texture's u axis runs vertically, so the tally scratches on bunker 5's box walls ran a different way on each wall and at a different scale from the small click panel. Replaced by one plane per wall with `plane.uvs` tiled (`[0,0, nx,0, nx,ny, 0,ny]` for the front and again for the back; `wrapMode` 0 = repeat) so the 1024 × 512 texture repeats as a 4 × 2 m tile at one scale on both walls, and both planes are pointer colliders named `Document: tally` / `Document: tally 2` (documents.ts wires numbered suffixes to the same text).
- **A per-frame assignment survives the reset it should stop at.** The kill set `flashlight.dead = 999` on every frame from the blackout to the end of the executor, so the respawn's `dead = 0` was overwritten a frame later and the light never came back. Guard timed side effects with the same window as the state they belong to (`t < 7.6`).
- **Per-line hold for the passage:** `holdFor(line) = max(4, 1.6 + words * 0.34)`; starts are precomputed once, so the HTN executor still waits on `telepathy.done`.
- **Captions stack by overwrite:** several queued captions share one HUD slot and the latest-pushed wins, so a caption fired by a repeating branch (`!window` every 5 s) hides everything else. Fire story captions once per occasion (`cabin.windowCaptionVisit`) and give repeating branches a `!wait`.
- **The generator was run while the scene was open in the Hub editor** (its data-layer server was up). The composite kept the changes, but the editor can write its own copy back; close the scene in the Hub before regenerating when possible.
- **The Explorer was closed when this pass was built**, so none of it has been verified in-world yet: the skill's launch and bind gates need the owner (Play with the MCP server on, then `/mcp reconnect explorer`).

## 2026-11-05 · Lessons from pass 7 (owner notes 5)

- **Custom plane UVs (`plane.uvs` with values > 1) rendered stretched in the Explorer** even with `wrapMode` repeat. Tiling a wall is safer by geometry: n planes with default UVs, each at the texture's own aspect (here 3 × 1.5 m for a 2:1 image). Twelve planes cost nothing.
- **A flat sprite can fly in 3D without a billboard:** orient it with `Quaternion.lookRotation(normal, travel)` where the travel direction is the smoothed frame-to-frame delta and the normal is "up for a level flyer" rolled about the travel axis by the wingbeat (`Quaternion.fromAngleAxis(roll, travel)`); the sprite's head is its local +y.
- **Captions and pages:** `Doc.after` lines are queued with `showCaption` once the page closes (edge detected in a system: open → closed), each held ~0.32 s per word; `captionsPending()` tells other systems how long the slot is busy so the voice can wait for it.
- **A gate at the start is a fact, not a timer in the executor:** `story.awake` flips on distance from the spawn (pass 9: 55 m, no timer), feeds the `dormant` fact, and the eyeshine target reads it directly so his eyes are dark whatever the branch.
- **The beam starts 0.55 m ahead of the camera** (`flashlight.ts`), so against glass the cone's apex is already through it; sill shelves 0.8 m deep keep the player back instead of moving the lamp (which would put the avatar's head in the cone).

## 2026-11-06 · Lessons from pass 10 (owner notes 8)

- **A paused clock needs shorter thresholds.** Once `lampOnFor` stopped counting while a page is open, the old 30/65/110 s meant 30 s of pure idling before anything happened, and players left. Thresholds are now a named constant (`CABIN` in host.ts) so the next retune is one line.
- **"Only eyes" is a branch, not an eyeshine tweak.** `shy` (awake, `cabin.visits === 0`, ignorant, not summoned) sits above every woods branch and runs one primitive, `!stand_off`, which keeps him at `bands.far + 6` in front of the player; the eyes target reads the same condition so the beam cannot light them to full.
- **A lit cabin is a landmark only if it emits.** A point light inside a closed room shows nothing from outside; the beacon is a porch `LightSource` plus an emissive bulb, and emissive on the glass panes (`Material.getMutable` on the generator's `Cabin: glass F/B/L/R`), all scaled by the same flicker factor as the bulb.

## 2026-11-05 · Lessons from pass 9 (owner notes 7)

- **A timer is not a gate.** `story.awake` on `clock > 110` meant that reading the first paper in the light woke him and `lit` was already `long`: he came straight to the gate. Now distance only (55 m), `flashlight.litFor = 0` at waking, and `VisibilityComponent` off on the model and the eyes while dormant (`body.setVisible`), so "not there yet" is literal rather than "dark eyes somewhere".
- **An ending that fades back invites the player to keep playing.** `hud.black` is pinned to 1 by the ending system once `story.ended`; nothing else may clear it.
- **Texts in one module.** `src/script.ts` exports `SIGN`, `OPENING`, `HINTS`, `CAPTIONS`, `OBJECTIVES` (tuples), `DEATHS`, `ENDINGS`, `VOICE`, `PAGES`; `documents.ts` keeps only the hooks (`HOOKS[key]`). Textures stay in the generator.
- **A pen note on a PIL texture:** draw on a transparent layer in a hand font (`Bradley Hand Bold.ttf`), rotate a few degrees with `expand=True`, paste with itself as mask; a loose `ellipse` in the same ink reads as a ring. Print fonts never read as handwriting whatever the colour.
- **Particle sprites:** `texture: { src }` on `ParticleSystem` (flat `Texture`, not the Material union); a 64 px radial glow with a four-point flare, `PSB_ADD`, `gravity: 0.6` so sparks arc down.

## 2026-11-05 · Lessons from pass 8 (owner notes 6)

- **A continuous emitter toggled by `active` is the reliable one-shot.** For the sparks the `ParticleSystem` runs with `rate: 180`, `active: false`, parented to the flashlight entity, and is switched on for 0.35 s; a `loop: false` burst cannot be retriggered cleanly.
- **Nothing may play on frame 1.** `frames.n` (audio.ts, a priority-1000 system) counts frames; ambience starts at frame 2, the cabin system returns early before that, the howl starts from its own system. The reason is the editor's mute, which only catches sounds started after the first frame.
- **Latching a fact from transient conditions:** `story.summoned` is set once (collar in hand, no page open, no captions pending) and never cleared, so a caption fired later cannot flip the plan back. The transient window between collar and summoned is its own fact (`hidden`) with its own branch.
- **Fence panels can be skipped by index** (`fence_side(..., skip=(1,))`) to put a gate in the line; the side's single invisible collider still closes it.
